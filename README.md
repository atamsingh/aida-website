# AIDA Consulting Solutions website

Static site for https://www.aidaconsulting.ca/ — plain HTML and CSS, generated by one Python script.

## Pages

| Page | Purpose |
| --- | --- |
| `/` | Home: AI-led positioning, services, results, contact |
| `/small-business/` | Landing page for small and medium business owners (main ad target) |
| `/ai-consulting/` | Landing page for "AI consulting" searches and ads |
| `/ai-agents/` | Landing page for AI agents, assistants and RAG |
| `/data-engineering/` | Landing page for technical buyers: pipelines, warehouse, cloud cost |
| `/ai-ready-data/` | Landing page for getting data ready for AI |
| `/blog/` | Blog index and six posts |
| `/public-sector/` | Landing page for government teams (not in the menu; reach it by URL or ads) |

## Editing

All page content lives in `build.py`. Edit it, then regenerate the HTML:

    python3 build.py

- `build.py` — content and page templates (no dependencies)
- `styles.css` — styling, light and dark themes
- `assets/contact.js` — sends the contact form to the Google Form behind it
- `assets/`, `partials/` — logo, favicon, share image, hero diagram
- `CNAME` — custom domain for GitHub Pages

Do not edit the generated `index.html` files by hand; they are overwritten by `build.py`.

## Blog

Each post is an HTML fragment in `posts/<slug>.html`, listed in `POSTS` in `build.py`
(title, summary, date, and `featured` for the four shown on the home page).
`posts/_BRIEF.md` is the writing brief: voice, allowed facts and format. The build prints
a note for any post that still contains a yellow `[ATAM: …]` marker.

## Booking link

Set `BOOKING_URL` at the top of `build.py` to a Calendly or Google Calendar booking
link and every main button becomes "Book a 30-minute call".

## Contact form

The on-page form posts into the existing "Contact information" Google Form, so
messages appear in that form's responses. The field ids are at the top of `build.py`.
Turn on email notifications for new responses in Google Forms to be alerted.

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000.

## Deploy

Hosted on GitHub Pages from the `main` branch (Settings → Pages → Deploy from a branch → `main` / root). Every push to `main` publishes.

## Logos

`assets/logos/` holds the Stripe, Shopify, Fullscript and EDC logos shown in the
"Where our principal has worked" strip. They are trademarks of their owners and are
used only to identify past and current employers. Stripe, Shopify and EDC files come
from Wikimedia Commons; the Fullscript file comes from fullscript.com. IRCC is shown
as text because Government of Canada symbols need Treasury Board authorization.
